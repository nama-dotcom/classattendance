# Class Attendance Tracker

A clean, responsive, and lightweight **Class Attendance Tracker** web application built with vanilla HTML, CSS, and JavaScript.

## Features

- **Add Attendance Records**: Record student attendance with student name, date, and status (Present / Absent).
- **Edit & Update**: Modify any existing record with live form population and quick updates.
- **Delete with Confirmation**: Safeguard against accidental deletion with a confirmation prompt.
- **Search & Filter**: Real-time search by student name with search term highlighting and status-based filtering (Present / Absent / All).
- **Live Statistics**: Summary counters at the top showing total records, present count, and absent count.
- **Friendly Empty State**: Helpful feedback when no records exist or when no search results match.
- **Local Persistence**: Saves all records to the browser's `localStorage` so data remains safe across page reloads.
- **Mobile Responsive**: Clean and accessible design that works seamlessly across desktops, tablets, and mobile devices.

## Tech Stack

- **HTML5** (Semantic structure)
- **CSS3** (Modern layout with CSS Grid & Flexbox, responsive design, custom variables)
- **JavaScript** (ES6+, Vanilla DOM manipulation, `localStorage` API)

## Getting Started

No installation, build tools, or backend servers are required.

1. Clone or download this repository:
   ```bash
   git clone https://github.com/nama-dotcom/classattendance.git
   ```
2. Open `index.html` in your favorite web browser.
